# java-number-programs

Java programs based on **number properties**, covering common mathematical and number-based programming problems at the Class XII level.

## What this repository contains

This repository contains **15 Java programs** that determine or demonstrate different properties of numbers.

1. **Palindrome** — checks whether a number remains the same when its digits are reversed.
2. **Armstrong** — checks whether a number is equal to the sum of the powers of its digits.
3. **Kaprekar** — checks whether a number satisfies the Kaprekar property.
4. **Perfect** — checks whether a number is equal to the sum of its proper divisors.
5. **Automorphic** — checks whether the square of a number ends with the number itself.
6. **Spy** — checks whether the sum of the digits is equal to the product of the digits.
7. **Disarium** — checks whether the sum of digits raised to their respective positions equals the number.
8. **Neon** — checks whether the sum of the digits of its square equals the number.
9. **Duck** — checks whether a number contains the digit zero.
10. **Harshad** — checks whether a number is divisible by the sum of its digits.
11. **Fascinating** — checks whether a number satisfies the Fascinating number property using its multiples.
12. **Magic** — checks whether repeated digit-sum reduction results in 1.
13. **Happy** — checks whether repeatedly summing the squares of digits eventually reaches 1.
14. **Strong** — checks whether the sum of the factorials of its digits equals the number.
15. **Evil** — checks whether the binary representation of a number contains an even number of 1s.
